## Subject

Permission request for a mobile web version and Lithuanian translation of BAARS-IV Other-Report forms

## Draft

Dear Guilford Permissions Team,

I am requesting permission to use the BAARS-IV Other-Report forms in a small web application that I built as a personal, noncommercial prototype.

I created it because other-report questionnaires are often completed by family members who live elsewhere. Sending a paper form or a desktop-oriented PDF adds friction, especially when the respondent uses a phone. The prototype gives each respondent a direct invitation link, presents one question at a time on a mobile screen, saves unfinished work in that browser, and produces a completed PDF for return by email. My aim is to make remote participation easier and reduce skipped questions or transcription mistakes. The application does not calculate scores, interpret answers, or provide a diagnosis.

The current prototype supports English and Lithuanian. I would like permission to:

- reproduce and display the BAARS-IV Other-Report forms and item wording in an interactive website;
- provide a Lithuanian translation alongside the English text;
- allow invited respondents to complete the form remotely on a phone or computer;
- generate a completed copy of the original form for the respondent to download and return;
- maintain the application code in a GitHub repository and host the review or approved application through GitHub Pages;
- make the tool available to psychiatrists or other licensed professionals who want to invite family members or other informants to complete an other-report form remotely; and
- add further translations in the future, subject to any review or approval process you require.

The prototype has no database, analytics, or network submission endpoint. Invitation details are encoded in the URL fragment. Answers stay in the respondent's browser unless the respondent downloads or emails the completed file.
